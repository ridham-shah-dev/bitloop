# BITLOOP

An IT social platform. Share posts, follow people and talk about tech. It is one single HTML file, with no install and no server.

**Live demo:** https://ridham-shah-dev.github.io/bitloop/

## How to run

1. Download `index.html`.
2. Open it in your browser.

That is all. The data (users, posts) is saved in your browser with `localStorage`, so it stays on your computer.

## What it has

- Register and login
- Posts and feed
- Glass style design with animations (GSAP)

## Built with

HTML, CSS and JavaScript in one file. GSAP for animations. Google Fonts (Orbitron, Share Tech Mono).
